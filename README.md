## Turn-Based Battle Game

A command-line Pokémon-style battle game written in C#.

### Current Features
- Creature stats
- Turn-based combat
- Damage calculation

### Planned Features
- Multiple moves
- Status effects
- Multiplayer (local)

### types
- fire: strong towards air, resistant to self
- water: strong towards fire
- earth: strong towards water 
- air: strong towards earth, resistant to self
